GitHub access

Saving updates the price file in the site's GitHub repository, so it needs a GitHub token with write access to it. The token stays in this browser and is only sent to GitHub.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → LHWS-Pricing.
  3. Permissions → Repository → Contents: Read and write. Generate it and paste it here.
